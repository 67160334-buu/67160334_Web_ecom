# 💎 FORME - เว็บขายเครื่องประดับออนไลน์ (Minimal Fine Jewelry E-Commerce)

เว็บไซต์ร้านค้าขายเครื่องประดับและเพชรแท้ออนไลน์ แบรนด์ **FORME** ในดีไซน์ **Minimal Editorial Luxury** สไตล์เรียบหรู คลีน สะอาดตา (Warm Ivory & Neutral Black) พร้อมระบบหลังบ้าน จัดการสินค้า คำสั่งซื้อ คูปองส่วนลด และระบบติดตามพัสดุครบวงจร

---

## ✨ ดีไซน์และฟีเจอร์เด่น (Minimal Design Highlights)

### 1. 🤍 มินิมอล สไตล์ Editorial Luxury
- **โทนสี Soft Ivory (#FAF9F6) & Deep Neutral (#121212)** สบายตา ดูแพงสไตล์แบรนด์จิวเวลรี่ระดับสากล
- **Typographic Elegance**: ใช้ฟอนต์ serif สวยสะกดตา *Cormorant Garamond* ผสานกับ *Inter* และ *Prompt*
- **แท็บหมวดหมู่แบบมินิมอล (Minimal Underline Tabs)**: ทั้งหมด, แหวน, สร้อยคอ, ต่างหู, กำไล & ข้อมือ, เซ็ตวิวาห์
- **การ์ดสินค้าแบบเรียบหรู**: รูปภาพคุณภาพสูง ขอบบางคมชัด สลับดูรายละเอียดได้สะดวกรวดเร็ว

### 2. 🔍 ค้นหาและคัดกรองสินค้า (Smart Minimal Filters)
- ค้นหาทันทีตามคำสำคัญ
- กรองตาม **ตัวเรือน** (ทองคำขาว 18K, ทองคำแท้ 18K, พิงก์โกลด์ 18K, เงินแท้ 925)
- กรองตาม **อัญมณี** (เพชรแท้ GIA, ไพลิน, ทับทิม, มรกต, ไข่มุก)
- เรียงลำดับตามความนิยม, ราคา, สินค้ามาใหม่, รีวิวสูงสุด

### 3. 💍 รายละเอียดสินค้า & วัดขนาดแหวน (Product Details & Size Guide)
- แกลเลอรีรูปภาพหลายมุมมอง
- **คู่มือวัดขนาดแหวน (Ring Size Guide Modal)**: ตารางเทียบไซส์แหวนมาตรฐานไทย/ญี่ปุ่น, ยุโรป, สหรัฐ พร้อมวิธีวัดด้วยตนเอง
- **เลือกขนาดแหวน (Ring Size Selector)**
- **บริการสลักชื่อเลเซอร์ฟรี (Laser Engraving)** กรอกข้อความบนตัวเรือนได้ทันที
- **รีวิวจากลูกค้าจริง** พร้อมแบบฟอร์มส่งรีวิวและให้คะแนนดาว

### 4. 🛒 ตระกร้าสินค้า & คูปอง (Minimal Cart Drawer)
- สไลด์ข้างแบบเรียบหรู
- หลอดคำนวณส่งฟรี (ซื้อครบ 2,000.- ส่งฟรีทั่วประเทศ)
- โค้ดส่วนลดที่รองรับ:
  - `WELCOME10` : ลด 10% เมื่อช้อปครบ 1,000.-
  - `SPARKLE500` : ลด 500.- เมื่อช้อปครบ 3,000.-
  - `LUXE20` : ลด 20% เมื่อช้อปครบ 10,000.-
- บริการห่อของขวัญและการ์ดอวยพรฟรี

### 5. 💳 ระบบชำระเงิน (Minimal Checkout Flow)
- กรอกที่อยู่จัดส่งทั่วไทย
- ตัวเลือกชำระเงิน:
  - **PromptPay QR Code Generator**: แสดง QR Code สแกนจ่ายพร้อมคำนวณยอดเงินจริง
  - **บัตรเครดิต/เดบิต**
  - **ผ่อนชำระ 0% 10 เดือน**
  - **เก็บเงินปลายทาง (COD)**
- หน้าใบเสร็จรับเงิน (Printable Order Receipt) พร้อมหมายเลขคำสั่งซื้อ (`FRM-YYYYMMDD-XXXX`)

### 6. 📦 ติดตามสถานะพัสดุ (Order Tracking)
- ค้นหาด้วยหมายเลขคำสั่งซื้อหรือเบอร์โทรศัพท์
- ไทม์ไลน์ 5 ขั้นตอน: รับคำสั่งซื้อ ➔ เตรียมสินค้า ➔ ตรวจคุณภาพ GIA ➔ จัดส่งพัสดุ ➔ จัดส่งสำเร็จ

### 7. ⚙️ แผงควบคุมหลังบ้าน (Admin Backoffice Dashboard)
- แดชบอร์ดสรุปยอดขายรวม, จำนวนออเดอร์, และเตือนสต็อกเหลือน้อย
- ตารางจัดการสถานะคำสั่งซื้อแบบเรียลไทม์
- ฟอร์มเพิ่มสินค้าเครื่องประดับใหม่เข้าสู่ฐานข้อมูล

## 🚀 วิธีเปิดใช้งาน (How to Run)

### วิธีที่ 1: ดับเบิลคลิกไฟล์ Batch
```
start.bat
```
ระบบจะเปิดเว็บเบราว์เซอร์ไปยัง `http://127.0.0.1:5000` อัตโนมัติ

### วิธีที่ 2: รันผ่าน Terminal / PowerShell
```powershell
cd c:\minsat_AAI\web_ecom
py app.py
```
จากนั้นเปิดเบราว์เซอร์ไปที่: **http://127.0.0.1:5000**
